# Limitations

The current universe is a current hot-token discovery backfill, not a
historical all-token universe. Binance Web3 wallet analytics, CEX spot/
perpetual, funding, OI, executable depth, gas, latency, and bridge data are not
in the verified current dataset. H001/H002 are exploratory real-data studies;
H003 and network diffusion are data-blocked. No result is labelled tradeable.
