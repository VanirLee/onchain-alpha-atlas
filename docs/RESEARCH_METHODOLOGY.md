# Research methodology

Research proceeds through:

`G0 data validity → G1 association → G2 mechanism/falsification → G3 purged
OOS → G4 economic significance → G5 execution feasibility`.

An event response is an association unless it has controls and a falsification
design. A lead-lag coefficient is predictive association, not causality.
Historical wallet PnL is not evidence of inside information. A result can only
be called `OOS_SUPPORTED` after chronological purged testing; it can only be
called `ECONOMICALLY_VIABLE` after real cost and execution constraints.
